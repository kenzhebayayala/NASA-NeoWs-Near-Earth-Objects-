# Data dictionary (NASA NeoWs, raw_data.csv, 203 жол, 13 баған)

| Өріс | Тип | Түрі | Сипаттама |
|---|---|---|---|
| record_id | str | идентификатор | Бірегей жазба ID (`neo_id_күні`), primary key |
| neo_id | str | идентификатор | NASA астероид ID, қайталануы мүмкін (бір астероид әр күні жақындайды) |
| name | str | категориялық | Астероид атауы, жақшамен жазылған, мысалы (2004 XK14) |
| nasa_jpl_url | str | мәтін | JPL деректер қорына сілтеме |
| absolute_magnitude_h | float | сандық | Абсолюттік жұлдыздық шама H (аз болған сайын астероид үлкен) |
| diameter_min_km | float | сандық | Диаметрдің ең аз бағасы, км |
| diameter_max_km | float | сандық | Диаметрдің ең көп бағасы, км |
| is_hazardous | bool | категориялық | NASA «потенциалды қауіпті» деп белгілеген бе |
| is_sentry | bool | категориялық | Sentry қауіп мониторинг жүйесінде бар ма |
| close_approach_date | date | күн/уақыт | Жерге жақындау күні (YYYY-MM-DD) |
| velocity_kmh | float | сандық | Салыстырмалы жылдамдық, км/сағ |
| miss_distance_km | float | сандық | Жердің жанынан өткен қашықтық, км |
| orbiting_body | str | категориялық | Қай дененің жанынан өтеді (Earth) |
